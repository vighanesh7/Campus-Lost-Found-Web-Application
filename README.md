# Campus Lost & Found

A full-stack web application that helps college students report lost and found items, search for missing belongings, and contact others to recover them. Built for the Full Stack Development syllabus.

**Tech Stack:**

- Frontend: React + Vite, React Router, Redux Toolkit, Axios
- Backend: Node.js + Express.js
- Database: MySQL + Sequelize ORM
- Authentication: JWT + bcrypt
- File Uploads: Multer
- Scheduled Tasks: node-cron
